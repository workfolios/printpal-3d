# Phase 3D Slice Two Known Limitations

- Local records are browser- and origin-specific.
- No user-facing backup or restore control is implemented yet.
- No Record Library or autosave interface is connected to the data layer.
- No cross-device synchronization, account recovery, or hosted backup exists.
- Schema migration behavior beyond database version 1 is not yet required.
- Repository hooks for reactive UI queries are deferred to Slice Three.

These limitations are intentional and do not expand the accepted Slice Two scope.
