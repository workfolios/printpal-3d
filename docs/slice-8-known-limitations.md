# Phase 3D Slice Eight Known Limitations

- Backup and Project transfer remain user-initiated file operations.
- Full Backup restore replaces all local records; merge-based restore is deferred.
- Project Markdown is readable but is not an import format.
- Project JSON import creates a new Project and does not update an existing Project.
- Export files are not encrypted or password protected by PrintPal.
- Users remain responsible for storing exported files appropriately.
- Browser and operating-system download behavior may vary.
- Local storage remains tied to the browser and application origin.
- No cloud backup, cross-device synchronization, authentication, or account recovery exists.
- Full accessibility and cross-browser certification remain assigned to Slice Nine; Slice Eight validates desktop and Pixel 7 Chromium workflows.
