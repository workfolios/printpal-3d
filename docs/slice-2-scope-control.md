# Phase 3D Slice Two Scope Control

## Included

- Dexie and IndexedDB foundation.
- Five typed local tables.
- Repository abstractions.
- Project and Attempt CRUD.
- Related Comparison, Next-Test-Plan, and App-Setting stores.
- Atomic create, cascade-delete, clear-data, and storage-count operations.
- Local-storage disclosure metadata.
- Persistence and rollback tests.

## Excluded

- Record Library interface.
- New Print interface.
- Autosave user experience.
- Planning-card persistence integration.
- Outcome capture.
- Attempt duplication.
- Attempt comparison logic.
- AI interpretation or next-test generation.
- Export and import implementation.
- Authentication, cloud sync, hosted storage, or external database.
- Deployment changes.

The excluded capabilities remain assigned to later controlled slices in the Phase 3D plan.
