# Phase 3D Slice Nine Known Limitations

- V0.4 remains a single-user, browser-resident product simulation without authentication or cloud synchronization.
- Local records remain tied to the current browser and application origin.
- Cross-device transfer remains a user-controlled export and import operation.
- Reference Tools remain non-persistent and are retained for backward compatibility and quick advisory use.
- No image upload, camera analysis, visual failure diagnosis, printer control, slicer control, or telemetry ingestion exists.
- Accessibility validation is automated and workflow-based; it does not constitute formal third-party accessibility certification.
- Cross-browser validation covers the governed Playwright browser matrix, not every browser version, operating system, assistive technology, or device combination.
- Export files are not encrypted or password protected by PrintPal.
- Deployment, hostname transition, production monitoring, and public release remain deferred.
